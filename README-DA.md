# Food Truck Empire — første prototype

Denne mappe er din byggepakke til Roblox Studio. Målet er én fungerende grill og én burger, der kan blive perfekt eller brænde på.

## Start her

Åbn `MORGEN-PLAN.md` og følg den én linje ad gangen i Roblox Studio. Brug `01-studie-opsætning.md`, hvis du vil have de samme trin med flere detaljer.

## Indhold

- `MORGEN-PLAN.md` — dag 1, tjekliste.
- `01-studie-opsætning.md` — samme opsætning, trin for trin.
- `scripts/Leaderstats.server.lua` — Cash-tæller for spilleren.
- `scripts/Grill.server.lua` — aktiv grill: tom → tilbereder → perfekt → brændt med ild.
- `scripts/Orders.server.lua` — valgfri kundeordre i `Workspace.CurrentOrder`.
- `cursor-prompts.md` — prompts, hvis du vil bygge videre bagefter.

Du skal ikke forstå al koden endnu. Indsæt kun ét script ad gangen, test det, og fortsæt derefter.
